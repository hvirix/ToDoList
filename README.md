# Cute To-Do List

**A stylish and interactive To-Do List application** crafted with HTML, CSS, and JavaScript as part of a learning project. This application features a modern **glassmorphism aesthetic**, smooth animations, and custom decorative elements for a more engaging user experience. 

It serves as a practical demonstration of front-end development skills, specifically focusing on DOM manipulation and advanced CSS positioning techniques.

### Quick Start
To get this project running locally, first **clone the repository** to your machine. Once inside the project folder, run the command `npm install` to set up all necessary dependencies from the package file. 

After the installation is complete, you can launch the application by running `node server.js` in your terminal and opening the local server address in your browser.
